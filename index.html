Cómo usar un efecto en tu web

Carga GSAP

Pega estas líneas antes de cerrar </body>. Desde la versión 3.13 todos estos plugins son gratuitos. O pulsa Descargar HTML en el código de un efecto y tendrás un archivo que ya funciona.

<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/gsap.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/SplitText.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/ScrollTrigger.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/TextPlugin.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/gsap@3.13.0/dist/ScrambleTextPlugin.min.js"></script>

Marca tu texto

Pon la clase titulo al elemento que quieras animar.

<h1 class="titulo">Hola, mundo</h1>

Pega el código

Registra los plugins una vez y después pega el código del efecto que hayas copiado.

gsap.registerPlugin(SplitText, ScrollTrigger, TextPlugin, ScrambleTextPlugin);

// …aquí el código copiado…
